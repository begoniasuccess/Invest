HOW TO READ

指標閱讀方式

方向平均報酬用核心方向換算後的隔日收盤報酬；正值才代表方向有利。
方向命中率核心多且隔日收漲，或核心空且隔日收跌的比例。
低收反彈隔日日盤最低點到收盤的距離，越大表示收盤離低點越遠。
高收回落隔日日盤最高點到收盤的距離，越大表示收盤離高點越遠。
