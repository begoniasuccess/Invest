# 台股關鍵點位整理

## 任務
自動判斷兩種輸入：
1. **加權指數 TAIEX**：今日開盤、收盤、最高、最低；五日均乖離上下限；5MA/10MA/20MA/60MA；「選權」價格清單。以「今日收盤」為基準。
2. **台指期 TX**：全日開盤、收盤、最高、最低；五日均乖離上下限；全日 5MA/10MA/20MA/60MA；日盤開收高低、日盤05MA/10MA/20MA/60MA、日盤轉折支撐與壓力；夜盤開收高低、夜盤轉折支撐與壓力。以「全日收盤」為基準。

自動偵測：有「全日收盤」或「日盤」「夜盤」時優先視為 TX；有「今日收盤」及「選權」時視為 TAIEX。若基準收盤缺失，應詢問，不能自行假設。

## 不可違反的規則
- 完整收集輸入的**每個價格及其標籤**，不得遺漏；包括價格重複時的所有標籤。
- 價格清除千分位逗號；忽略 Markdown 表格分隔符號、HTML 空白實體與裝飾符號。
- 百分比重新計算：`(price - close) / close * 100`，**四捨五入至小數第二位（ROUND_HALF_UP）**。正數帶 `+`，負數帶 `-`，零為 `0.00%`。不照抄來源括號內百分比，來源百分比僅供參考。
- 價格**嚴格由高至低**排序；**僅完全相同的價格**合併標籤，依輸入先後保留順序，使用 ` / ` 分隔；不合併相近價格。
- 基準收盤的那一行，在所有合併標籤後附上 `（基準）`，百分比為 `(0.00%)`。
- 五日均乖離：若輸入兩個點位卻都寫「乖離上限」，**數值較小者**一律標 `五日均乖離下限 -2.0%`，較大者標 `五日均乖離上限 +2.0%`；不以其相對基準的正負來決定。來源括號內百分比也不決定標籤。
- TAIEX「選權」未分類價格：`price > close` → `選權壓力`，`price < close` → `選權支撐`，`price == close` → `選權`。若來源明確標註支撐或壓力，保留來源標註。
- TX 的「日盤轉折點」與「夜盤轉折點」按**表頭對應**的支撐/壓力欄位讀取，不要假設表頭固定為支撐在前；即使壓力低於基準、支撐高於基準，也不改動標籤。
- 全日 OHLC 與日盤、夜盤 OHLC 為不同標籤，不能因數值看似不一致而改寫；全日收盤不一定等於夜盤收盤。使用使用者給定的全日收盤。
- `日盤05MA` 與 `5MA` 是不同標籤；`日盤10MA` 與 `10MA` 亦然。不要因接近而合併。
- 只輸出**一個純文字 code block**，每行 `價格 標籤 (+X.XX%)`，不加入解盤、進出場建議或其他敘述。
- 資料不足、無法明確判讀時，先問一個必要的問題，不要編造價格。

## 執行方式
1. 將輸入辨識為 TAIEX 或 TX。
2. 逐行讀取原始資料，整理為 `[{price: integer, label: string}, ...]`。讀取表格時依表頭匹配支撐/壓力。
3. 檢查是否包含基準收盤及所有 OHLC、均線、選權或轉折點。
4. 將記錄交給 `scripts/format_levels.py` 的 `format_levels(close, records)`；若可執行 Python，應優先使用此腳本以減少計算誤差。腳本接收 JSON，支援 `--input`，詳見 README.md。
5. 核對輸出項目總數：每個不同價位都必須有一行，重複價位的所有標籤必須完整。
6. 僅輸出 code block。
